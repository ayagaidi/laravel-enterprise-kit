# Laravel Enterprise Kit v0.1.0

The first public foundation release of **Laravel Enterprise Kit**: a production-minded Laravel 13 starter for internal tools, business systems, administrative portals and enterprise applications.

## Foundation included

- Laravel 13 / PHP 8.3+
- session authentication with login rate limiting
- active/disabled account enforcement for web and Sanctum API requests
- self-contained roles and permissions with stable permission slugs
- protected `super-admin` privilege boundary
- last-active-super-admin lockout protection
- user and role administration
- append-only audit events with actor/request metadata
- redaction of common password/token/secret fields from audit payloads
- cached public/private system settings
- versioned `/api/v1` boundary with Laravel Sanctum
- Arabic/English locale switching and RTL/LTR admin layout
- SQLite-first local setup with MySQL-friendly configuration
- reproducible dependencies through a committed `composer.lock`
- PHPUnit feature tests + Laravel Pint in GitHub Actions

## Security behavior covered by tests

The initial suite exercises both allowed and denied paths for authentication and authorization, including:

- guest protection
- disabled web accounts
- disabled API users with otherwise-valid Sanctum tokens
- RBAC route enforcement
- prevention of non-super-admin privilege escalation
- protection of existing super-admin accounts
- prevention of disabling or demoting the last active super administrator
- audit event creation without password leakage
- public/private settings API separation

## Design goal

This release deliberately focuses on **security and architecture primitives before business modules**. Documents, notifications, queues, approvals, SSO and observability remain roadmap items rather than partially implemented features.

## Install

```bash
cp .env.example .env
composer install
php artisan key:generate
touch database/database.sqlite
php artisan migrate --seed
php artisan serve
```

To create a local demo administrator, explicitly set `SEED_ADMIN_PASSWORD` in your local `.env`. No admin password is committed to the repository.

## Upgrade / compatibility

This is the first tagged release, so there is no prior stable contract to migrate from. Future releases will document breaking changes and upgrade paths.
